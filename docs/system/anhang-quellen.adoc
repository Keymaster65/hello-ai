[[quelldateien]]
= Quelldateien

Die Kapitel nennen Dateien und Klassen, beschreiben sie aber nur. Dieser Anhang enthält sie
im Original – damit eine Aussage über den Code am Code selbst überprüfbar ist, ohne zwischen
Dokument und Repository zu wechseln.

*Eingebunden, nicht kopiert.* Jeder Eintrag ist ein `include` der Datei aus dem
Arbeitsverzeichnis. Es gibt keine zweite Fassung, die veralten kann; der Anhang zeigt den
Stand, den das Repository beim Rendern hatte.

Daraus folgt eine Zusicherung, die diese Dokumentation vorher nicht hatte: Ein fehlender
`include` ist als *Build-Fehler* konfiguriert
(link:{adr}/0022-asciidoc-systemdokumentation-in-docs-system{adrext}[ADR 0022]). Wird eine Datei
umbenannt, verschoben oder gelöscht, *bricht `./gradlew build`* – und zwar an der Stelle, an
der die Dokumentation noch den alten Pfad nennt. Die Dateiverweise der Systemdokumentation
sind damit maschinell geprüft, nicht nur gut gemeint.

.Bedienung
* Jeder Eintrag ist *zugeklappt*; ein Klick auf den Pfad öffnet ihn.
* Verweise aus den Kapiteln – etwa <<src-recipe,`Recipe.java`>> – springen direkt auf den
  Eintrag. Verlinkt ist die Stelle, an der eine Datei *eingeführt* wird, nicht jede
  Wiederholung ihres Namens.
* Jeder Eintrag ist aus den Kapiteln erreichbar: einzeln oder über den Verweis auf seine
  Gruppe. Dateien ohne Aussage über die Struktur – Einstiegspunkte, Stylesheet, Testhilfen –
  sind nur über die Gruppe verlinkt.
* Die Reihenfolge folgt den Schichten von innen nach außen, danach Frontend, Tests und Build –
  dieselbe Richtung wie im Kapitel Bausteine und Schichten.

.Nicht enthalten
[cols="2,3", options="header"]
|===
| Was | Warum

| Generierte jOOQ-Klassen
| Entstehen beim Build aus dem Changelog und liegen unter `build/`. Ihre Quelle ist
  <<src-changeset-schema>>.

| `modules/frontend/src/api/schema.d.ts`
| Wird aus dem OpenAPI-Contract erzeugt. Die Quelle sind die Java-DTOs samt Annotationen.

| `modules/frontend/package-lock.json`
| Maschinell gepflegt, mehrere Tausend Zeilen ohne Aussage über das System.

| Gradle-Wrapper (`gradlew`, `gradle/wrapper/`)
| Enthält eine Binärdatei; Festlegung und Begründung stehen in
  link:{adr}/0009-gradle-wrapper-verbindlich{adrext}[ADR 0009].

| `docs/**`
| Die Dokumentation selbst. Master-Prompt und Skills stehen im Wortlaut in <<wortlaut>>, die
  ADRs sind im Abschnitt Architekturentscheidungen (ADR) verlinkt. Ausgenommen ist
  <<src-docinfo-footer>>: CSS und JavaScript sind Quelltext, kein Text zum Lesen.
|===
